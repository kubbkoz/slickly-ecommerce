# Elevating Slickly's Design: Advanced GitHub UI/UX Libraries, Claude Skills & Inspiration Resources

## TL;DR
- **For Slickly's Nuxt 3 + Vue stack, the highest-leverage open-source toolkit is a four-library motion/3D core — Inspira UI (~4.7k stars), Vue Bits (~4k), TresJS (~3.5k) for WebGL product showcases, and Lenis (14,135 stars) for smooth scroll — combined with the now-100%-free GSAP for cinematic scroll storytelling.** All are actively maintained (commits/releases within the last 1–4 months as of June 2026) and Vue/Nuxt-native or framework-agnostic.
- **For Claude Code, install Anthropic's official `frontend-design` skill (from `anthropics/skills`, ~149k stars, and mirrored in `anthropics/claude-code`) — its guidance explicitly references the exact "near-black background with a single bright acid-green accent" look Slickly already uses, so you must feed it the brand brief to push past that as a default rather than land on it by accident.** Supplement with `VoltAgent/awesome-design-md` for drop-in DESIGN.md brand specs and `travisvn/awesome-claude-skills` as the discovery index.
- **For inspiration, reference curated "awesome" repos — `gztchan/awesome-design`, `darelova/Awesome-Design-Resources-List`, `emmabostian/design-inspiration`, and `birobirobiro/awesome-shadcn-ui` — which collectively point to dark, high-contrast, automotive/luxury galleries (Awwwards, Land-book, Mobbin, BentoGrids).** Vet each linked site for the black + acid-yellow, bold-display aesthetic before adopting.

## Key Findings

Slickly's brand (#080808 black, #C8FF00 acid yellow, Bebas Neue display, DM Sans body, "MAKE IT SLICK") is an aggressive, high-contrast automotive aesthetic that rewards motion, depth, and tactile micro-interactions. The Vue/Nuxt ecosystem now has mature equivalents to the React animation tooling that powers most Awwwards-grade sites, so you do not need to leave your stack. The three categories the user asked about map cleanly:

1. **Advanced UI/animation/3D libraries** — Vue-native motion (Motion for Vue, @vueuse/motion, Vue Bits, Inspira UI), WebGL (TresJS + Cientos + post-processing), smooth scroll (Lenis), and the universal animation engine GSAP (now free, including ScrollTrigger/SplitText).
2. **Claude Code design skills** — Anthropic's official `frontend-design` and `canvas-design` skills, plus community skill packs and curated indexes.
3. **Design inspiration repos** — "awesome" lists and markdown link collections, plus the newer DESIGN.md token-spec repos that double as inspiration and as machine-readable design systems.

## Details

### 1. Advanced UI / UX / Animation / 3D Libraries (Vue/Nuxt-first)

**Motion for Vue (`motiondev/motion`, motion.dev/docs/vue)** — The Vue port of the library formerly known as Framer Motion, now an independent MIT-licensed project. It is the most capable declarative animation library for Vue: a `<motion>` component, variants, gestures, layout animations, and scroll-triggered/scroll-linked animations via `whileInView` and `useScroll`. Offers a Nuxt module (`motion-v/nuxt`) with auto-imports. **Application to Slickly:** Use for hero entrance sequences, add-to-cart confirmation micro-interactions, and product-card hover states. Pair acid-yellow accent reveals with spring physics for a "snappy, premium" feel that matches the bold brand.

**@vueuse/motion (`vueuse/motion`, ~2.7k stars, latest release v3.0.3 on March 10, 2026)** — A lighter-weight, well-maintained Vue composables library with a `v-motion` directive, 20+ presets, SSR-ready, first-class Nuxt 3 support, <20kb bundle. **Application:** Ideal for the broad sweep of scroll-reveal animations across product listing and content pages where you want low bundle cost. Use it as the default and reach for Motion for Vue only where you need gesture/layout complexity.

**Vue Bits (`DavidHDev/vue-bits`, ~4k stars, last commit ~May 2026)** — The official Vue port of React Bits [GitHub](https://github.com/DavidHDev/vue-bits) . Per the 2025 JavaScript Rising Stars (risingstars.js.org), react-bits ranked third overall, adding 26,200 new GitHub stars ("react-bits, a collection of animated components for background effects, text animations … achieved 26,200 new stars"; PkgPulse cites 37.1K total stars and #1 in the React Ecosystem category). Vue Bits brings that to Vue with 90+ animated, highly customizable components: text animations, animated backgrounds (including WebGL/Three.js and Matter.js-backed ones), and UI effects, installed individually via the jsrepo or shadcn CLI so you own the code. **Application:** This is your fastest path to "wow" sections — animated headline treatments for "MAKE IT SLICK" using Bebas Neue, particle/ballpit backgrounds in acid yellow on black, and splash-cursor effects. Copy-paste model means no heavy dependency lock-in.

**Inspira UI (`unovue/inspira-ui`, ~4.7k stars, actively maintained through April 2026)** — A community-driven Vue/Nuxt collection that brings the aesthetics of Aceternity UI and Magic UI (React-only) to Vue. Built on shadcn-vue, @vueuse/motion, and Tailwind. [GitHub](https://github.com/unovue/inspira-ui/blob/main/README.md) Components include glow border, lamp effect, link preview, particle image, marquee, and more. Endorsed publicly by Nuxt creators. **Application:** "Lamp effect" and "glow border" components are tailor-made for a dark theme with a single bright accent — frame premium product cards or category tiles with acid-yellow glow on #080808. Works alongside Nuxt UI, shadcn-vue, Vuetify, or Quasar. [Inspira-ui](https://inspira-ui.com/)

**TresJS (`Tresjs/tres`, ~3.5k stars, MIT, updated March 2026)** — The leading declarative Three.js renderer for Vue: build 3D scenes as Vue components with full reactivity, HMR, TypeScript, and Vue DevTools integration. [TresJS Docs](https://docs.tresjs.org/getting-started) Official Nuxt module `@tresjs/nuxt` auto-imports the ecosystem and supports GLSL shader imports. [Nuxt](https://nuxt.com/modules/tresjs) Extended by:
- **Cientos (`@tresjs/cientos`)** — the Vue equivalent of react-three-drei: helpers/abstractions (OrbitControls, environment maps, stars, loaders).
- **TresJS post-processing (`@tresjs/post-processing`)** — powered by pmndrs/postprocessing: bloom, chromatic aberration, glitch, depth of field.

**Application:** This is the centerpiece for premium automotive/detailing product visualization. Render hero detailing products (bottles, applicators, machine polishers) as interactive 3D models with bloom and a studio HDR environment, let users orbit/zoom, and drive a color/finish configurator. Bloom post-processing on an acid-yellow rim light against black is exactly the high-end showroom look. Note: heavy 3D needs performance budgeting on mobile — lazy-load the canvas and provide a static fallback. For reference implementations, the GitHub `3d-configurator` and `product-configurator` topics host numerous open-source Three.js/react-three-fiber car and product configurators (e.g., `rendercodeninja/automotive-configurator`, `theshanergy/4x4builder`) whose architecture and material/color-picker logic port readily to TresJS.

*(Alternative/legacy: TroisJS (`troisjs/trois`, ~4.5k stars) is the older r3f-style Vue 3D library but appears not actively maintained — latest commit ~3 years ago [Made with Vue.js](https://madewithvuejs.com/troisjs) — so prefer TresJS.)*

**Lenis (`darkroomengineering/lenis`, 14,135 stars, MIT, latest release v1.3.23 dated April 15, 2026)** — The de facto smooth-scroll standard, lightweight and performance-focused, [GitHub](https://github.com/darkroomengineering/lenis?tab=readme-ov-file) with first-class adapters: `lenis/vue`, `nuxt-lenis`, and tight GSAP ScrollTrigger sync. Powers WebGL scroll syncing and parallax. [GitHub](https://github.com/darkroomengineering/lenis?tab=readme-ov-file) **Application:** The foundation for scroll-based storytelling — a buttery scroll feel instantly signals "premium." Sync Lenis with GSAP ScrollTrigger to pin sections, drive parallax product reveals, and tie 3D camera moves to scroll position for a brand narrative ("from grime to slick").

**GSAP (`gsap.com`, GreenSock) — now 100% free including all plugins** — GSAP became 100% free with the v3.13 release on April 30, 2025, after Webflow's acquisition of GreenSock announced Oct 15, 2024 (Webflow Blog, "Webflow makes GSAP 100% free"): "everyone — whether or not you're a Webflow customer — will be able to leverage all of GSAP's tools completely free of charge, including the previously paid Club plugins." That includes ScrollTrigger, SplitText, MorphSVG, DrawSVG, and ScrollSmoother, with commercial use covered. GSAP is framework-agnostic and works with Vue/Nuxt. **Application:** The engine for cinematic scroll sequences and millisecond-precise timelines. Use SplitText to animate "MAKE IT SLICK" character-by-character in Bebas Neue, ScrollTrigger for pinned product storytelling, and MorphSVG for logo/icon transitions. **Caveat:** GSAP's free license is owned/funded by Webflow and contains a restriction prohibiting use in tools that compete with Webflow, and Webflow can terminate the license at its discretion; for a normal e-commerce store this is a non-issue, but if total licensing independence matters, Motion for Vue is MIT and irrevocable.

**Nuxt UI (`nuxt/ui`) — supporting foundation** — The official Vue UI library (Reka UI + Tailwind), with ready templates. Not "cutting-edge" per the user's brief, but the right accessible, themeable base layer (buttons, forms, modals, toasts) on which to layer the motion/3D libraries above. **Application:** Use as the utilitarian component substrate (checkout, account, filters) and reserve Inspira UI / Vue Bits / TresJS for the showcase surfaces.

### 2. Claude Code Skills for UI/UX Design

Claude "Skills" are SKILL.md instruction folders (sometimes with helper scripts) that load on demand to teach Claude specialized behavior. The relevant design ones:

**`anthropics/skills` (~149k stars, official, actively maintained)** — Anthropic's canonical skills repo. The two design-critical skills:
- **`frontend-design`** — Guidance for distinctive, intentional visual design; instructs Claude to commit to a bold aesthetic direction (brutalist, luxury, retro-futuristic, editorial, etc.) before coding, and to treat typography, color (CSS variables), motion, and spatial composition as core pillars. **Critically for Slickly:** the skill text explicitly names "a near-black background with a single bright acid-green or vermilion accent" [GitHub](https://github.com/anthropics/skills/blob/main/skills/frontend-design/SKILL.md) as one of three current AI-default looks to be wary of — which is nearly identical to Slickly's black + acid-yellow. The skill states the brief's own words always win, so you should feed it the precise Slickly brand tokens (#080808, #C8FF00, Bebas Neue, DM Sans) so Claude executes the look deliberately rather than treating it as generic slop.
- **`canvas-design`** — "Philosophy first, expression second" workflow [Claudecn](https://claudecn.com/en/blog/claude-official-skills-walkthrough/) for producing museum/magazine-quality static visual art (PNG/PDF), with a bundled `canvas-fonts` directory. **Application:** Generate brand collateral, social ad creative, and packaging mockups consistent with the Slickly identity.
- Also includes **`theme-factory`** (10 curated theme systems + on-the-fly theme generation from brand colors) and **`brand-guidelines`** — useful for enforcing visual consistency.

Install: `git clone https://github.com/anthropics/skills.git [Snyk](https://snyk.io/articles/top-claude-skills-ui-ux-engineers/) ` then copy `skills/frontend-design` into `~/.claude/skills/`.

**`anthropics/claude-code` (~133k stars, official)** — Hosts the same frontend-design skill under `plugins/frontend-design/skills/frontend-design/SKILL.md`, installable via the plugin marketplace (`/plugin marketplace add anthropics/claude-code`).

**`travisvn/awesome-claude-skills` (~11–13k stars, updated Feb 2026)** — The curated discovery index for Claude skills, with a design/UI section. **Application:** Your starting map for finding and vetting new skills.

**`VoltAgent/awesome-agent-skills` (~23.5k stars, updated May 2026)** — A 1000+ entry agent-skills index referencing canvas-design, frontend-design, algorithmic-art, Google Labs' design-md/Stitch skills, and more. [GitHub](https://github.com/VoltAgent/awesome-agent-skills)

**Community frontend-design skill packs** (smaller, vet before installing):
- **`Koomook/claude-frontend-skills`** — Plugin for "distinctive, non-generic" frontend designs [GitHub](https://github.com/Koomook/claude-frontend-skills) based on Anthropic's "Improving Frontend Design Through Skills" post; [GitHub](https://github.com/Koomook/claude-frontend-skills) four-dimensional approach (typography/color/motion/backgrounds) to avoid AI-slop. [GitHub](https://github.com/Koomook/claude-frontend-skills)
- **`Ilm-Alan/frontend-design`** — Works across Claude Code, Codex, and Gemini CLI; defines eight "aesthetic anchors," each locking palette, typography, and texture to specific CSS tokens. [GitHub](https://github.com/Ilm-Alan/frontend-design) **Application:** The token-locking model is a clean way to encode the Slickly palette as a reusable anchor.
- **`wilwaldon/Claude-Code-Frontend-Design-Toolkit`** — A curated meta-guide of skills, plugins, MCP servers, and CLAUDE.md tricks [GitHub](https://github.com/wilwaldon/Claude-Code-Frontend-Design-Toolkit) (Figma MCP, baseline-ui, accessibility/perf pipeline) for better Claude frontend output. [GitHub](https://github.com/wilwaldon/Claude-Code-Frontend-Design-Toolkit)
- **`HermeticOrmus/LibreUIUX-Claude-Code` (~25 stars)** — A large UI/UX system (agents, plugins, commands, skills) [github](https://github.com/HermeticOrmus/LibreUIUX-Claude-Code) including a design-mastery plugin covering UI/UX, WCAG accessibility, and design vocabulary. Small audience but comprehensive scope.

**Security caveat:** Skills execute instructions and can bundle scripts. Snyk's ToxicSkills audit (snyk.io/blog, published Feb 5, 2026) scanned 3,984 agent skills from ClawHub and skills.sh and found prompt injection in 36.82% (1,467 skills), with 534 (13.4%) flagged critical: "13.4% of all skills (534 of 3,984) contain critical-level security issues." Always review SKILL.md and any bundled scripts before installing community skills.

## Recommendations

**Stage 1 — Foundation (week 1–2):** Add `Lenis` (via `nuxt-lenis`) for smooth scroll and `@vueuse/motion` for baseline scroll-reveal animations across all pages. These are low-risk, low-bundle, Nuxt-native, and immediately raise perceived polish. Install Anthropic's official `frontend-design` skill into your Claude Code setup and feed it the exact Slickly brand tokens. **Benchmark to proceed:** Lighthouse performance stays ≥90 on mobile and CLS <0.1 after adding smooth scroll.

**Stage 2 — Showcase surfaces (week 3–5):** Layer `Inspira UI` (lamp/glow components for product/category cards) and `Vue Bits` (animated "MAKE IT SLICK" hero text in Bebas Neue, acid-yellow particle backgrounds). Adopt `GSAP` + ScrollTrigger + SplitText (now free) for one flagship scroll-storytelling sequence on the homepage. **Benchmark:** A/B the new hero against the current one; proceed to Stage 3 only if engagement (scroll depth, add-to-cart rate) holds or improves and mobile FPS stays ≥50.

**Stage 3 — 3D product visualization (week 6+):** Pilot `TresJS` + `Cientos` + post-processing (bloom) on a single hero SKU as an interactive 3D viewer/configurator (adapting an open-source car/product configurator from the GitHub `3d-configurator` topic). Lazy-load the WebGL canvas, ship a static image fallback, and gate it behind a "View in 3D" interaction so it never blocks initial render. **Benchmark:** Only roll out to more SKUs if the 3D viewer measurably lifts conversion/time-on-page for the pilot product and Largest Contentful Paint remains <2.5s.

**Throughout — design inputs:** Pull DESIGN.md specs from `VoltAgent/awesome-design-md` (NVIDIA, Spotify, SpaceX) as Claude inputs, and use `darelova/Awesome-Design-Resources-List` galleries (A1 Gallery, Mobbin, Land-book) to assemble a focused moodboard of dark automotive/luxury e-commerce references before each build.

**Decision rule on animation engine:** Default to GSAP for complex timelines (free, mature, best ScrollTrigger). If license independence becomes a strategic concern, standardize on Motion for Vue (MIT, irrevocable) instead — accept a modest reduction in timeline-orchestration power.

## Caveats
- **Star counts are approximate and dated June 2026**; several community skill repos (Koomook, Ilm-Alan, wilwaldon) are small (hundreds of stars or fewer) and their exact counts could not be verified — evaluate them on code quality, not popularity. `VoltAgent/awesome-design-md` star figures conflict across trackers (~69k per its README vs. ~91.7k elsewhere), reflecting very rapid recent growth. `obra/superpowers` showed an anomalously high star figure that conflicts with early-2026 sources and is an engineering/workflow framework, not a design library.
- **The `frontend-design` skill's built-in warning about "near-black background with a bright acid accent" being an AI default is a genuine risk for Slickly** — the brand could read as generic AI output if executed lazily. Differentiation must come from execution: real automotive textures, Bebas Neue's distinctive condensed display, motion that serves the detailing narrative, and restraint (the skill itself warns excessive animation reads as AI-generated).
- **Performance vs. spectacle trade-off:** WebGL (TresJS) and heavy scroll animation can harm Core Web Vitals and mobile UX, which directly affect SEO and conversion in the SK/CZ/PL markets. Every effect should be lazy-loaded, reduced-motion-aware (`prefers-reduced-motion`), and performance-budgeted.
- **Security:** Community Claude skills can contain prompt injection or malicious scripts (per Snyk's ToxicSkills audit above); review every SKILL.md and bundled script before installing, and prefer official Anthropic skills where possible.
- **Some sources (vendor blogs, "best of" listicles) carry marketing framing**; the core technical facts here (library capabilities, GSAP licensing change, official skill contents) are drawn from primary repos and official announcements, but star counts and "fastest-growing" claims should be re-verified at implementation time.
