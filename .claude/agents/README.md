# Claude Code subagents

Sourced from [msitarzewski/agency-agents](https://github.com/msitarzewski/agency-agents) (MIT licensed —
see `LICENSE` in this directory), copied verbatim (no reformatting needed — the source
files already use Claude Code's subagent frontmatter).

Curated subset — 114 of the upstream repo's 264 agents:

- **engineering** (58), **design** (10), **testing** (9), **security** (12),
  **product** (5), **project-management** (7) — full divisions, relevant to this
  Nuxt/Shopware storefront.
- **marketing** (13) — a hand-picked subset (SEO/AEO/AI-search, content, social,
  email, growth, PR); the upstream `marketing/` division's China-platform-specific
  agents (Douyin, WeChat, Weibo, Xiaohongshu, Baidu, etc.) and other divisions
  (sales, finance, healthcare, GIS, academic, game-development, spatial-computing,
  paid-media) were left out as not relevant to this project.

To pull in more agents later, browse the source repo's category folders and copy
individual `.md` files here — no conversion needed for Claude Code.
